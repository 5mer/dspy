# Шутер в лабиринте

3D-шутер от первого лица на Python и Ursina. Исследуй случайно сгенерированный лабиринт, сражайся с врагами и найди выход.

## Возможности

- Пистолет и дробовик, перезарядка и рикошеты.
- Аптечки, броня и сбор патронов.
- Настройка размера лабиринта через меню.
- Время прохождения и статистика победы.

## Запуск

Сохрани код в `main.py` и добавь модели и текстуры, указанные в коде, сохранив пути к ресурсам.

```bash
pip install ursina
python main.py
```

## Управление

- **WASD** — передвижение.
- **Мышь** — обзор, **ЛКМ** — стрельба.
- **Shift** — бег.
- **R** — перезарядка.
- **1 / 2** — выбор оружия (2 надо найти).
- **Esc** — меню и перезапуск.
